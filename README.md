# 🍽️ Employee Management System

A full-featured Employee Management System built with Java, 
designed to manage employee records efficiently.

## 🚀 Features
- Add, update, delete employee records
- Search and filter employees
- Clean GUI interface using Java Swing
- Data persistence with file/database storage

## 🛠️ Tech Stack
- **Language:** Java
- **UI:** Java Swing
- **Database:** MySQL / File I/O
- **IDE:** IntelliJ IDEA / Eclipse

## ⚙️ How to Run
1. Clone the repository
```bash
   git clone https://github.com/Ashvinlodhi/EmployeeManagement.git
```
2. Open in IntelliJ IDEA or Eclipse
3. Run `Main.java`
